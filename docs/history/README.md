# docs/history — notes from the first catalogue pipeline

Decision records, how-to guides and record changelogs written while the catalogue was built with
`build_catalog.py` (until commit `0dad25c`). They are kept as the history of the records: who
changed what and why. Paths and commands in them refer to the old layout (`records/<ID>.yaml`,
`spec/`, `build_catalog.py`); the current ones are in the [README](../../README.md) and
[`docs/standard.md`](../standard.md). Changes after the migration are in
[`CHANGELOG.md`](../../CHANGELOG.md).
