## Rules beyond presence

- minimum: no contact with the licensor role (who grants the licence)
- minimum: public resource with no location (URL) in data
- minimum: restricted / non-public resource without access_note (how to obtain it)
- minimum: LicenseRef-… licence without its text (license_text) or link (additional_links rel: license)
- minimum: every contact needs an organization and its roles
- minimum: every data entry needs a name
- recommended: no citation and no DOI
- recommended: temporal.update_frequency missing (use unknown if the source does not say)
- recommended: vector data entry without geometry_type
- recommended: licence without an SPDX code (confirm whether one exists)
- recommended: spatial coverage: give geography and bbox
- recommended: temporal coverage: give date or start_date (or the source's text)
- recommended: every data entry should say how it is reached (access_method) and what it holds (kind)
- recommended: citation: give authors and date (or at least the text)
- profile `mosaic`: MOSAIC ids are MFL-YYYY-NNN
- profile `mosaic`: spatial.landscapes missing (use the living landscapes it covers)
